# Here to Learn Consultants

Static website for Here to Learn Consultants, a network of educational consultants supporting schools across Asia.

## Pages
- `index.html` Home
- `services.html` Services (start-up, policy and curriculum, leadership, improvement and growth)
- `about.html` About and network
- `contact.html` Enquiry form

## Structure
- `assets/css/styles.css` Theme (graphite, bone and brass, industrial high-end)
- `assets/js/main.js` Navigation, scroll reveals, enquiry form
- `assets/img/` Favicon and future imagery
